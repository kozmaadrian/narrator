Shortcuts & how it works

Everything Narrator does, in three steps.

  1. 1WriteType the script, pick the voice, then Generate.
  2. 2SyncAdd your recording and set when each paragraph starts.
  3. 3ApplyWrites the timing into the script as pause lines and renders again.

1ScriptYou're here

    Script syntax

    • [pause 2s] [500ms] [1.5] adds silence. It replaces the automatic pause at that spot; [pause 0s] means none. Before the first sentence, it delays the voice.
    • A blank line starts a new paragraph.
    • # note lines are not read out.
    • Pronunciation: select a word, press Add, and spell it the way it should sound.

    2SyncYou're here

      Good to know

      • Click a row to jump there and tap from it, or pause and press the row's timer button.
      • An empty Start keeps the rendered gap after the paragraph before. The reset button puts back the rendered Start.
      • A negative Start on ¶1 starts the voice before the video.
      • Changes play live. A paragraph is never cut off: if the one before is still speaking, it waits for it.
